# منصة تحليل البورصة المصرية 🇪🇬📈 — Trading Terminal

منصة تحليل وتداول احترافية لأسهم البورصة المصرية (EGX) — Python + Streamlit، مجانية بالكامل،
**بأسعار حقيقية موحدة من مصدر واحد** وبيانات موثقة المصدر.

## ✨ المميزات

- **📊 أسعار حقيقية موحدة**: كل الأسعار والمؤشرات من واجهة TradingView الرسمية (نفس أرقام الموقع) — 283+ سهماً حقيقياً بأسمائها العربية، والقائمة تُبنى تلقائياً (لا أسهم ميتة ولا ناقصة)
- **🏛️ شريط تيرمنال حي**: EGX30 + عدّاد الصاعدين/الهابطين + حالة السوق بتوقيت القاهرة الرسمي (مع التوقيت الصيفي) — تحديث كل 30 ثانية
- **📈 رسم احترافي بمحرك TradingView**: نفس محرك ثاندر والمنصات العالمية — فترات من دقائق لسنوات، أدوات رسم، مؤشرات
- **⚡ التحليل اللحظي**: خيار تحديث شمعة اليوم بالسعر الحقيقي قبل حساب المؤشرات الثمانية عشر والقرار
- **🎖️ فرص عالية الثقة**: فلترة صارمة + نسبة النجاح التاريخية **الصافية بعد العمولات** لكل فرصة
- **📜 سجل توصيات موثق**: كل توصية تُسجَّل بتاريخها وسعرها ولا تُحذف — المنصة تقيس نفسها بالأرقام
- **🎯 مراقبة صفقات لحظية**: دخول + وقف + أهداف مع تنبيهات وصول الهدف أو ضرب الوقف
- **📰 أخبار حقيقية لكل سهم**: عناوين محدّثة من Google News بالعربية مع المصدر والتاريخ
- **🏙️ أداء القطاعات**: متوسط تغير أسهم كل قطاع يومياً من أسعار السوق الفعلية
- **🔧 19 مؤشراً فنياً**: RSI, StochRSI, MACD, ADX, Bollinger, OBV, MFI, Supertrend, ATR وأنماط الشموع والدايفرجنس

## 🚀 التشغيل

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
أو مباشرة بـ `run.bat` — ثم افتح `http://localhost:8501`

## 🧭 التبويبات

| التبويب | المحتوى |
|---|---|
| 🏠 السوق | مؤشرات البورصة، أداء القطاعات، الرسم، الفاحص الشامل بالخريطة الحرارية |
| 💡 الفرص | ترشيحات المحرك + الفرص عالية الثقة + سجل التوصيات الموثق |
| 🎯 التداول والقرار | قرار الخبير، خطة تنفيذ رقمية، رسم TradingView، التحليل اللحظي، الأخبار |

```
    ├── news.py             # الأخبار الحقيقية (Google News RSS)

    ├── fundamental.py      # التحليل المالي

    ├── expert_advisor.py   # محرك القرار + وايكوف + تعدد الأطر
    ├── advisor.py          # ترشيحات الفرص (تصنيف آلي بالقيمة السوقية)
    ├── screener.py         # فاحص السوق
    ├── backtest.py         # اختبار رجعي صافي بعد العمولات (0.55%)
    ├── performance.py      # الأداء التاريخي
    ├── risk.py             # إدارة المخاطر وحجم المركز
    ├── storage.py          # تخزين دائم (متابعة/صفقات/تنبيهات/سجل توصيات)
    ├── live_verify.py      # حالة السوق بتوقيت القاهرة الرسمي
    └── tv_widgets.py       # ويدجت TradingView المدمجة
```

## ⚠️ شفافية البيانات

- الأسعار والمؤشرات: TradingView (مؤجلة ~15 دقيقة وفق قواعد البورصة المصرية — نفس تأخير كل المنصات المجانية)
- الرسوم التاريخية: Yahoo Finance (بيانات الإغلاق الرسمية)
- مؤشرات مالية أساسية (توزيعات/ROE): قاعدة مرجعية محلية مدققة يدوياً — قارن دائماً مع آخر إفصاح رسمي
- لا توجد أي بيانات وهمية أو تجريبية في المنصة، وكل رقم معروض له مصدر

**هذه الأداة للاسترشاد والتحليل فقط — ليست نصيحة استثمارية.**
