# منصة تحليل البورصة المصرية 🇪🇬📈

أداة تحليل استثمارية متكاملة لأسهم البورصة المصرية (EGX)، مبنية بـ **Python + Streamlit**،
تعمل مجاناً بالكامل وتستخدم بيانات **Yahoo Finance**.

## ✨ المميزات

- **🎯 القرار الاستثماري** — إشارة (شراء / بيع / انتظار) بدرجة ثقة واضحة مع الأسباب
- **📉 التحليل الفني** — RSI, MACD, المتوسطات المتحركة (SMA), Bollinger Bands, ATR
- **🏦 التحليل المالي** — مكرر الربحية (P/E), القيمة السوقية, نمو الإيرادات, عائد التوزيعات
- **🛡️ إدارة المخاطر** — تقييم المخاطر، حجم المركز (Position Sizing)، إيقاف الخسارة (Stop Loss)، أهداف جني الأرباح
- **📈 رسوم بيانية تفاعلية** — شموع يابانية، خطية، Bollinger، مع مستويات الدعم والمقاومة

## 🚀 التشغيل

### 1) تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2) تشغيل التطبيق
```bash
streamlit run app.py
```

ثم افتح المتصفح على الرابط الذي سيظهر (غالباً `http://localhost:8501`).

## 🧭 الاستخدام

1. من **الشريط الجانبي** اختر السهم من قائمة أسهم البورصة المصرية، وحدد الفترة الزمنية.
2. حدد **رأس المال** ونسبة المخاطرة والحد الأقصى للسهم من المحفظة.
3. تصفّح التبويبات الخمسة للحصول على التحليل الكامل.

## ⚠️ تنبيه

هذه الأداة لأغراض **التحليل والاسترشاد فقط**، وليست نصيحة استثمارية.
قرارات الاستثمار مسؤوليتك، ويُنصح بالتشاور مع مستشار مالي معتمد.
